Provenance & limits

Compact exports omit guard and storage-route evidence. This viewer validates structure and timestamps; it does not re-verify the original recording or establish gameplay meanings or visibility. A joined trace does not prove unchanged object identity.

Import bounds: 128 MiB file, 256 KiB per line, 100,000 frames, 128 fields, 1,000,000 field samples, 32 MiB retained numeric payload. Browser object overhead is additional. A limit failure rejects the whole import; samples are never silently dropped.

Open this HTML file directly. No server, network requests, external libraries or telemetry. Keep this folder’s files together.
